Gotchas from this session:
- Magic `box values` returns internal units but reads bare numbers as lambda (2x internal at magscale 1 2); use `um` or an `i` suffix.
- A Magic session holding a cell open (file lock) keeps the old version; a save from it overwrites batch edits. Check `/proc/*/fd` or ask the user to close it first.
- Don't render xschem PNGs or open GUI windows unless asked (`check_sch.sh --png` pops windows without xvfb).
